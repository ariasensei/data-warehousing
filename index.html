Course Description

Data Warehousing is a CHED-aligned Computer Science course that introduces students to the principles, architecture, design, implementation, optimization, and management of enterprise data warehouses. Students learn how organizations collect, integrate, transform, and analyze data from multiple operational systems to support Business Intelligence (BI), Decision Support Systems (DSS), and advanced analytics. Throughout the semester, students will design dimensional models, build ETL pipelines, develop OLAP solutions, create Business Intelligence dashboards, optimize query performance, explore cloud data warehouse platforms, and implement an enterprise-grade data warehouse solution using industry-standard and open-source tools.

  • Laboratory Activity 1
    Design a Data Warehouse Architecture for a real-world organization.

  • Laboratory Activity 2
    Create a Star Schema using Fact and Dimension Tables.

  • Laboratory Activity 3
    Implement the Data Warehouse Database using PostgreSQL or MySQL.

📊 MIDTERM LABORATORY

  • Laboratory Activity 1
    Develop a complete ETL Pipeline using Pentaho or Talend.

  • Laboratory Activity 2
    Develop Interactive Business Intelligence Dashboards using Apache Superset or Metabase.

  • Laboratory Activity 3
    Optimize the Data Warehouse using Indexing, Partitioning and Query Optimization.

ENTERPRISE FINAL PROJECT

Enterprise Data Warehouse System

Students will design, develop, implement, optimize, document, and defend a complete Enterprise Data Warehouse solution for a real-world organization. The project must integrate concepts learned throughout the semester, including Data Warehouse Architecture, ETL Pipelines, Dimensional Modeling, Business Intelligence, Performance Optimization, Cloud Technologies, and Data Governance.
